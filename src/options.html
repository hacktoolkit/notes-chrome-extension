Reminders

Backup & vault

Notes are stored in this browser profile. Export them as Markdown files, one per page, with YAML frontmatter that Obsidian understands.

Shared stickies

Someone sent you a .pagenotes.txt file? Import it here or paste it in the popup. Their stickies land on your note for that page; if it was encrypted, enter the passphrase they gave you.

Vault folder

Connect a folder, in your Obsidian vault or a synced drive such as iCloud Drive, and your notes live there as Markdown files: written on every save, and read back every few minutes so several browser profiles connected to the same folder share one notebook. Each profile keeps its own schedule; the files are plain Markdown any browser or app can read. The browser asks you to re-allow access once per session.

This browser has folder access turned off. Brave disables the File System Access API by default. To turn it on, open brave://flags/#file-system-access-api, set it to Enabled, and relaunch. Chrome and Edge support it out of the box. Export and import work everywhere.

Settings

Keep captures of pages you noteEach time you save an entry or open the popup on a noted page, store what the page looks like (title, metadata, text) in this browser. That is what powers "changed since your last visit" and profile insights. Never sent anywhere.
Sync with the vault folderWrite every save to the connected folder and read other profiles' changes back every few minutes.

Page identity rules

A note follows its page across URL variants: a pull request and its Files tab, a Jira issue and its board link, a profile and its subpages. Rules are regular expressions with a key template, the same format as Organize Tabs. Test a URL to see the key it gets.

Help

Add a noteClick the toolbar icon on any page and type. It saves as you type. Each day you write becomes a dated entry; click an earlier entry to edit it in place.
Capture a quoteSelect text on a page, right-click, "Add selection to this page's note".
Remind meOne click under the editor: 1h, tonight, tomorrow, next week, or pick a time. The page reopens at that time with a notification.
Snooze a tabCloses the tab now and reopens it later. Also in the right-click menu and as a keyboard shortcut.
ExportBackup & vault downloads every note as Markdown, or writes them into an Obsidian vault folder.
